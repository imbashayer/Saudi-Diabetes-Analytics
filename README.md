Saudi Diabetes Analytics

An interactive data analytics and machine learning project exploring diabetes patterns in a synthetic Saudi population dataset.

Project Overview

This project aims to demonstrate how statistical analysis, data science, and machine learning can be used to explore diabetes-related patterns and risk factors in a Saudi population.

The dataset is synthetically generated and designed using selected published research estimates and assumptions. It does not represent real patients or actual clinical records.

Key Features

* Synthetic Saudi diabetes dataset generation
* Data cleaning and exploratory data analysis (EDA)
* Statistical analysis and prevalence comparisons
* Calibration and validation against selected reference estimates
* Logistic regression modeling
* Model performance evaluation
* Confusion matrix and threshold analysis
* Risk factor exploration
* Interactive Streamlit dashboard

Technologies Used

* Python
* Pandas & NumPy
* Scikit-learn
* Plotly
* Streamlit
* Matplotlib & Seaborn

Project Structure

* App/ – Interactive dashboard
* Data/ – Synthetic dataset
* Scripts/ – Data generation and analysis scripts
* Models/ – Trained models
* Outputs/ – Generated outputs
* Results/ – Analysis and evaluation results

How to Run

Install the required dependencies:

pip install -r requirements.txt

Run the dashboard:

streamlit run app.py

Adjust the dashboard file path if app.py is inside the App directory.

Important Disclaimer

This project uses synthetic data for educational and portfolio purposes only. It does not contain real patient information and must not be used for medical diagnosis, treatment, or clinical decision-making.
