## Saudi Diabetes Analytics 🇸🇦

An interactive data analytics and machine learning project exploring diabetes-related patterns and risk factors in a synthetic Saudi population dataset.

# Live Dashboard

Launch the Interactive Dashboard

# Project Overview

This project demonstrates how statistical analysis, data science, and machine learning techniques can be applied to explore diabetes-related patterns in a Saudi population.

The project uses synthetically generated data informed by selected published research estimates and documented assumptions. It does not contain real patient records.

# Project Objectives

* Explore diabetes and prediabetes patterns across age and sex groups.
* Examine associations between diabetes and selected risk factors.
* Compare synthetic estimates with selected reference estimates.
* Apply statistical analysis and logistic regression.
* Evaluate model performance using classification metrics.
* Present findings through an interactive dashboard.

# Key Features

* Synthetic dataset generation.
* Data cleaning and exploratory data analysis (EDA).
* Statistical analysis and prevalence comparisons.
* Calibration against selected reference estimates.
* Logistic regression modeling.
* Model evaluation and threshold analysis.
* Confusion matrix and feature importance analysis.
* Interactive Streamlit dashboard.

# Technologies

* Python
* Pandas and NumPy
* Scikit-learn
* Plotly
* Streamlit
* Matplotlib and Seaborn

# Methodology

The workflow includes:

1. Synthetic data generation.
2. Data preparation and quality checks.
3. Exploratory data analysis.
4. Statistical analysis.
5. Calibration and comparison with selected reference estimates.
6. Logistic regression modeling.
7. Model evaluation and interpretation.
8. Interactive dashboard development.

# Main Project Files

* app.py — Streamlit dashboard application.
* synthetic_saudi_diabetes.py — Synthetic data generation script.
* data_generation.ipynb — Data generation notebook.
* synthetic_saudi_diabetes_central.csv — Central synthetic dataset.

# Run Locally

Clone the repository:

git clone https://github.com/imbashayer/Saudi-Diabetes-Analytics.git
cd Saudi-Diabetes-Analytics

Install dependencies:

pip install -r requirements.txt

Run the dashboard:

streamlit run app.py

Important Disclaimer

This project uses synthetic data for educational and portfolio purposes only. The dataset does not represent real individuals or actual clinical records.

The analysis and predictive models are not intended for medical diagnosis, treatment, or clinical decision-making.
